# Vue + Express Starter

Fullstack application using:

- Typescript
- Vue 3
- Express.js
- Knex.js
- Pinia
- TailwindCSS

## Install

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Backend:

```bash
cd backend
npm install
npm run dev
```

## Build

Frontend:

```bash
npm run build
```

Backend:

```bash
npm run build
npm start
```
